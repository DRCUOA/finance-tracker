{# Statement helper — the recon-helper tool, merged into Finla. Shows a bank statement (OFX/QFX or CSV) as a tickable list, ordered like the reconcile screen (date ascending, statement order within a day), so each statement line can be checked off as it is cleared in the tracker. The file is parsed in the browser tab and never uploaded; tick progress lives in localStorage, keyed to the statement (bank FITIDs when the file has them), so a session survives a reload and can be exported/imported as JSON. Include once per page. Context variables (set before {% include %}): rh_embedded – true inside the reconcile screen's split pane: fixed-height, internally scrolling, "Follow difference" control, tracker balance cross-check rh_scope – account id; the last session is remembered per scope rh_expected_balance – the statement balance the reconciliation was started with (embedded only) Behaviour is window.reconHelper(root) below; every [data-recon-helper] root on the page mounts itself. The instance hangs off root.__reconHelper: setFind(minor|null) – highlight lines whose |amount| equals minor cents (the reconcile screen feeds its live difference in) getStats() – {loaded, tickedMinor, remainingMinor, done, total} and it dispatches a bubbling `recon-helper:stats` CustomEvent (same shape in event.detail) whenever the numbers change. #}
